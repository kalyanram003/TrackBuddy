# TrackBuddy

TrackBuddy is a project that leverages modern technologies for backend and frontend development.

## Backend Specifications
- **Java Version:** 21
- **Framework:** Spring Boot 3.5.4
- **Database:** PostgreSQL
- **Security:** Spring Security with JWT
- **Additional Features:**
  - Email sending capability
  - PDF generation functionality
  - API Documentation using Swagger

## Frontend Specifications
- **Framework:** React 18
- **Styling:** Tailwind CSS
- **Routing:** React Router v6
- **HTTP Client:** Axios

This combines all the necessary tools to create a robust and scalable application, providing an excellent user experience and secure backend integration.
